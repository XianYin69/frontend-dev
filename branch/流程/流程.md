# 流程（frontend-dev）

前端开发技能执行主干：`需求理解 → 现状核对 → 编码实现 → 本地预览 → 自检 → 审查 → 收尾`。
回环：自检/审查不通过 → 回 [编码实现](./编码实现/编码实现.md) 修复；素材不足 → 回 [需求理解](./需求理解/需求理解.md) 补充。

## 步骤列表

| 步骤 | 路径 | 说明 |
|---|---|---|
| 需求理解 | [需求理解/](./需求理解/需求理解.md) | 定改动类型与验收标准，产出 change-plan |
| 现状核对 | [现状核对/](./现状核对/现状核对.md) | 读既有代码与资源引用，防覆盖/死链 |
| 编码实现 | [编码实现/](./编码实现/编码实现.md) | 四分支：结构/样式/交互/框架 |
| 本地预览 | [本地预览/](./本地预览/本地预览.md) | 静态服务 + 浏览器验证 |
| 自检 | [自检/](./自检/自检.md) | 断链/404/HTML 有效/双语同步 |
| 审查 | [审查/](./审查/审查.md) | 衔接 web-design-guidelines 与 webapp-testing |
| 收尾 | [收尾/](./收尾/收尾.md) | 变更清单、提交建议、可选 PR |

## 使用脚本

`scripts/check_site.py`（自检）、`scripts/preview_serve.py`（预览）、`scripts/browser_interaction.py`（浏览器取证）。
