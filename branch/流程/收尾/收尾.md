# 收尾

终止节点。交付与留痕。

## 动作

1. 汇总变更清单：文件 × 改动类型 × 对应 change-plan 条目 × 验证结果（预览/自检/审查）。
2. 遗留建议：非阻断的审查建议、未验证项、后续优化。
3. 版本操作（git 仓库内）：建议提交信息；用户同意后提交；远端发布可选委托 `create-pull-request` 技能。
4. 预览服务与 tmp/preview 取证：交付后停服务；取证随任务归档或清理（先问）。

## 约束

- 未经用户确认不得 push / 建 PR / 删除取证。
- 双语站变更清单须按语言对分页呈现，便于对照验收。

## 决策分支

- 交付完成 → 节点结束。发现新的长期模式 → 回写 `references/` 沉淀。
