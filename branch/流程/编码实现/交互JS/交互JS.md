# 交互JS

操作分支（编码实现·C）。行为与微交互。

## 动作

1. 渐进增强：内容先在无 JS 下可读可用，JS 仅增强（导航、语言切换、折叠等）。
2. 反馈即时：可点元素有 hover/focus/active 态；操作结果 ≤400ms 有视觉回应。
3. 键盘可达：焦点顺序符合阅读顺序，Esc/Enter 语义正确；禁 tabindex 正值。
4. 可供性与一致性：同类控件同类行为（笔记见 `references/interaction-books.md`）。
5. 事件绑定用委托/命名空间，避免全局污染；脚本放对应 `scripts/` 目录。

## 兜底

- 交互无法本地验证（依赖后端/第三方） → 降级为静态检查并明确告知未验证项。
