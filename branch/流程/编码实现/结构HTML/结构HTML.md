# 结构HTML

操作分支（编码实现·A）。页面结构与内容。

## 动作

1. 语义化标签：header/nav/main/section/footer；标题层级不跳级。
2. `<html lang>`、`<title>`、meta description 与页面语言一致。
3. 新建页复制同类模板页范式（如 `Article/article-content.html`），保留导航/语言切换骨架。
4. 双语同步：zh-CN 与 en-US 对应页同结构创建/修改，互链正确。
5. 图片必须 alt；链接文本不得为空或「点击这里」类含糊词。

## 依据 / 兜底

- 范式缺失 → 读同类现存页反推；再无 → 向用户要参考页。
- 设计取向见 [样式CSS](../样式CSS/样式CSS.md) 与 `references/design-books.md` 层级条目。
