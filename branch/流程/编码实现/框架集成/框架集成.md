# 框架集成

操作分支（编码实现·D）。Vue/React 引入与协同。

## 动作

1. 优先级：既有页面保持原生不动 > 局部岛屿（island）嵌入 > 独立构建项目。
2. 无构建链静态站：CDN + 全局变量挂载（Vue 或 React+babel-standalone 仅原型期）；正式组件化才引入 npm 构建。
3. 框架岛与双语机制兼容：lang 切换、导航高亮沿用站点现有约定。
4. 产物与源码目录分离；`.gitignore` 排除 `dist/node_modules`。

## 兜底

- 用户环境无 node → 推荐无构建方案并说明局限，经确认再实施。
- 框架版本与站内旧脚本冲突 → 隔离挂载点（自定义元素/独立根节点）。
