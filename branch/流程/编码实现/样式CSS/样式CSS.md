# 样式CSS

操作分支（编码实现·B）。视觉与响应式。

## 动作

1. 移动优先：默认样式为窄屏，`min-width` 媒体查询逐级增强。
2. 设计令牌优先：颜色/间距/字号取自现有 CSS 变量或样式表提取，禁止大段内联样式。
3. 应用栅格/视觉层级/对比/留白原则（摘要笔记见 `references/design-books.md`，改动说明须引用条目号）。
4. 触控目标 ≥ 44px；正文对比度满足 WCAG AA（衔接 [审查](../../审查/审查.md)）。
5. 暗色/亮色若站已有机制则沿用变量，不自建第二套。

## 兜底

- 站无设计系统 → 从高频页面提取临时令牌并告知用户，建议后续沉淀。
- 需求要求照图实现但无设计稿 → 向用户索要或按站内既有风格收敛。
