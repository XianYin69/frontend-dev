# 审查

操作节点。外部技能衔接 + 设计规范人工复核。

## 动作

1. 规范审查：调用 `web-design-guidelines` 技能，对改动页做 UI/可访问性合规检查。
2. 行为验证：调用 `webapp-testing` 技能跑交互路径（导航、语言切换、折叠展开）；可访问性深检用 axe 扫描（Playwright 内置方案见 [a11y 清单](../../../references/a11y-checklist.md)）。
3. 汇总发现分为：阻断（回 [编码实现](../编码实现/编码实现.md)）/ 建议（列入收尾报告）。

## 兜底

- 两个外部技能任一未安装 → 使用 `references/a11y-checklist.md` 精简清单自查并声明「未做自动验证」。
- 静态页无交互路径 → 仅做渲染与可访问性检查。

## 决策分支

- 通过 → [收尾](../收尾/收尾.md)
