# 本地预览

操作节点。改动后先看再验。

## 动作

1. 起静态服务：`python scripts/preview_serve.py <站根> [端口]`（默认 8000，仅本机回环）。
2. 取证：`python scripts/browser_interaction.py <url> --out tmp/preview/`（截图 + 控制台错误 + 网络失败清单）。
3. 逐改动页对照 change-plan 验收标准查看；响应式改动须 375px / 768px / 1280px 三档截图。

## 兜底

- Playwright/浏览器内核缺失 → 降级：仅起服务并输出 URL，提示人工查看（不可静默跳过取证）。
- 服务端口冲突 → 自动换端口并在报告中记录实际端口。
- 页面依赖远端 CDN → 断网时标注「外链未验证」。
