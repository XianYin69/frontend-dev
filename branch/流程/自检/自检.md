# 自检

操作节点。机械校验，先于人工审查。

## 动作

1. `python scripts/check_site.py <站根> --pages <改动页...>`：
   - 悬空链接（站内 href/src 目标不存在）必须为 0；
   - 资源引用完整性（css/js/img 均存在）；
   - HTML 基础有效性（title/lang/alt/重复 id）；
   - 双语同步（zh-CN ↔ en-US 页一一对应、互链有效）。
2. 输出报告存 `tmp/preview/check-report.md`，与现状核对基线比对（不得新增死链）。

## 判定

- 全部通过 → 进入 [审查](../审查/审查.md)。
- 任一失败 → 携带失败清单回 [编码实现](../编码实现/编码实现.md) 修复；同一失败连续 3 次 → 停下询问用户。

## 兜底

- 脚本不可用 → 按上述四项手工 grep 抽查并声明降级。
