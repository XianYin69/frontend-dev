# resistance（frontend-dev 约束库）

不可逾越规则与执行期兜底。每步「错误 → 兜底 → 约束」均入本表。

## 红线

1. 未出 change-plan 并经用户确认，不得修改任何站点文件；覆盖写/删除/push/PR 必须先获同意。
2. 双语站改动必须双语同步（zh-CN ↔ en-US 成对校验），除非用户显式豁免。
3. 自检/审查未通过的改动不得进入收尾；同一失败连续 3 次停手问用户。
4. 引用外部脚本/CDN 进页面须注明出处并锁定版本；禁止引入未知来源内联脚本（XSS 面）。
5. 预览服务仅绑 127.0.0.1；不得暴露端口到公网。
6. 本目录约束不得删除；.md/脚本 ≤50 行；悬空链接 = 0。

## 错误-兜底-约束表

| 错误场景 | 兜底 | 约束来源 |
|---|---|---|
| 目标页/模板找不到 | 列候选问用户 | 需求理解 |
| 引用资源已缺失 | 报告并纳入修复范围或豁免 | 现状核对 |
| node/playwright 缺失 | 纯 Python 检查 + 人工查看声明 | 本地预览 |
| 端口占用 | 自动顺延并记录实际端口 | scripts/preview_serve.py |
| web-design-guidelines / webapp-testing 未安装 | a11y-checklist 精简自查并声明 | 审查 |
| 无 git 仓库 / gh 未登录 | 仅改文件+输出变更清单；推送留待凭据就绪 | 收尾 |
| 双语缺对应页 | 默认成对创建；用户豁免则记录 | check_site.py |

## 外部依赖边界

- 仅调用已注册技能与 MIT 依赖；网络检索不上传站点私有内容。
- 权限模型随 SMS：read 默认开，write/execute/network 逐项授予，未授予即拒绝。
