# 现状核对

操作节点。动代码前先读代码，防重复、防死链、防覆盖。

## 动作

1. 读取目标页及其引用的 CSS/JS/图片清单；新样式先查既有选择器与变量，避免重复定义。
2. 核对双语对应页是否存在、结构是否一致（模板页对照 Article/News 范式）。
3. 列出将被修改/覆盖的文件与区段，回填 change-plan。
4. 页面含外链/锚点时记录到自检基线（供 [自检](../自检/自检.md) 比对）。

## 兜底

- 目标页引用了不存在的资源 → 报告用户，纳入本次修复范围或显式豁免。
- 非 git 仓库 → 提示可先 init/备份，用户拒绝则仅做增量编辑不做破坏性重写。

## 决策分支

- 通过 → [编码实现](../编码实现/编码实现.md)
