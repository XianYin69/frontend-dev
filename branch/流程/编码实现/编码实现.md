# 编码实现

汇聚节点。按 change-plan 选择一个或多个分支实施，全部完成后汇入 [本地预览](../本地预览/本地预览.md)。

## 分支

| 分支 | 触发 | 节点 |
|---|---|---|
| A 结构 | 新建/改 DOM、meta、双语导航 | [结构HTML/](./结构HTML/结构HTML.md) |
| B 样式 | 视觉、布局、响应式、主题 | [样式CSS/](./样式CSS/样式CSS.md) |
| C 交互 | 行为、动效、组件逻辑 | [交互JS/](./交互JS/交互JS.md) |
| D 框架 | Vue/React 引入或协同 | [框架集成/](./框架集成/框架集成.md) |

## 通用约束

- 最小改动原则：只动与需求相关的区段；风格随现有代码。
- 设计与交互决策须引用 `references/` 设计条目并注明（见 [知识库索引](../../../references/references.md)）。
- 回环入口：自检/审查失败时带着失败证据回到本节点。
